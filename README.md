# 원헬스 건강 캠페인

가족이 한 팀이 되어 건강 실천 사진·감정·이야기를 기록하는 웹앱입니다. 웹 화면과 API 프록시는 Vercel, 기록과 비공개 사진은 준비된 Supabase 프로젝트를 사용합니다.

**직접 배포:** [01-직접-배포-안내.html](./01-직접-배포-안내.html)을 열고 안내를 따라 주세요. 설정 파일은 [02-연결-설정-만들기.html](./02-연결-설정-만들기.html)에서 본인이 만듭니다. 이 파일 묶음을 전달하는 것만으로 배포되지는 않습니다.

- 캠페인 코드 없이 7자 이내 팀 이름과 숫자 4~8자리 팀 비밀번호로 참여합니다.
- 영역은 양치·신체활동·건강식사·건강생활·건강한대화·기타(20자 이내)입니다.
- 가족의 얼굴이 나오지 않는 사진을 제출하도록 안내합니다. 사진과 기록은 해당 팀과 선생님만 인증 후 확인할 수 있습니다.
- 참여 마감은 2026년 10월 31일 23:59:59 한국 시간입니다. 날짜가 다른 참여 기록을 누적 참여일로 계산합니다.
- 1·3·7일 참여 보상을 보건실에서 한 번에 수령합니다. 7일 참여 후 소감문을 제출한 가족 중 선생님이 최대 20팀을 추가 상품 대상으로 선정합니다.
- Google 설문지는 선생님 공간에서 나중에 연결할 수 있습니다. 설문에는 학번·이름·팀 이름을 받습니다.

## 파일 구성

`public/`는 화면·폰트·그림·홈 화면 아이콘, `api/index.mjs`는 Vercel 서버 프록시입니다. `supabase/`는 기존 서버의 소스와 스키마 참고 파일입니다. 이미 준비된 프로젝트에 `schema.sql`이나 `storage.sql`을 다시 실행하지 마세요.

내부의 `FAMILY_*` 환경 변수, `family_*` 테이블과 `family-health` 함수 이름은 기존 연결을 유지하기 위한 이름입니다. 원헬스 브랜드로 표시하더라도 바꾸지 않습니다. Supabase 관리자 키는 브라우저나 Vercel 환경 변수에 넣지 않습니다.

## 개발자 로컬 확인

Node.js 22 이상이 필요합니다. 외부 런타임 의존 패키지는 없습니다. 실제 API 확인에는 생성한 연결키를 로컬 `.env`로 설정해야 하며, 연결한 Supabase에 실제 기록이 저장됩니다.

```sh
npm run build
npm test
npm run dev
```

실제 환경 파일과 초기 설정키는 소스나 ZIP에 포함하지 마세요. 초기 교사 설정은 서버의 `FAMILY_SETUP_TOKEN`으로 보호하며 선생님이 직접 8자 이상의 교사 비밀번호를 정합니다. 홈 화면 추가 기능은 iPhone·Android 안내를 제공하며, 기록·사진 API를 오프라인 캐시에 저장하지 않습니다.


## 단일 HTML 미리보기

프로젝트 폴더의 `index.html`은 이미지와 글꼴을 모두 포함한 단일 파일입니다. 더블클릭해 브라우저로 열면 디자인과 예시 참여 화면을 확인할 수 있습니다. 파일 미리보기에서는 실제 기록이 저장되지 않습니다. 배포용 진입점은 `public/index.html`이며 Vercel 배포 시에는 프로젝트 전체를 올려 주세요.
